# Project Rules

## Bilingual UI

- This website must always maintain feature parity between the English and Chinese versions.
- When modifying the UI, interactions, content structure, components, state, or page flows in either language, always review and update the other language version as needed.
- Never complete a change for only one language.
- After every bilingual change, verify that switching languages does not cause missing text, layout issues, or mixed Chinese and English content.
- When adding user-facing copy, always provide both Simplified Chinese and English translations and keep them in the shared copy configuration.
- Visual UI changes—including color, spacing, typography, placement, and component styling—should apply to both language versions by default, unless explicitly requested otherwise.
