# Rider–Waite–Smith card faces

These 78 local card-face images are public-domain Rider–Waite–Smith scans, created by Pamela Colman Smith under the direction of Arthur Edward Waite and first published in 1909.

Source: Wikimedia Commons, via the [TarotCards Rider–Waite collection](https://github.com/mixvlad/TarotCards).
